# Spotify 2023 Data Analysis Dashboard

## Project Overview
This project analyzes Spotify’s Most Streamed Songs 2023 dataset to uncover trends and insights from music streaming data. The dashboard focuses on artist performance, streaming behavior, musical attributes, and playlist reach.

The dataset contains 953 songs and provides valuable insights into what drives popularity on streaming platforms.

---

## Objectives
- Analyze top streamed artists and songs
- Identify streaming trends by release year
- Examine relationships between danceability and streams
- Compare major and minor musical keys
- Analyze BPM distribution and song performance
- Evaluate multi-platform playlist appearances

---

## Key Insights
- The Weeknd, Taylor Swift, and Ed Sheeran ranked among the most streamed artists.
- Most popular songs were released between 2021 and 2023.
- Songs in major keys slightly outperformed songs in minor keys.
- High BPM songs recorded strong average stream counts.
- Danceability showed a weak relationship with streaming success.
